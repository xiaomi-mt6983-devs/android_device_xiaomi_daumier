Device configuration for Xiaomi 12 Pro Dimensity
=============================================================

The Xiaomi 12 Pro Dimensity (codenamed _"daumier"_) is a high-end smartphone from Xiaomi.
It was announced and released in July 2022 Only for sale in China.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Mediatek Dimensity 9000+ (MT6983)
CPU     | Octa-core (1x3.2 GHz Cortex-X2 & 3x2.85 GHz Cortex-A710 & 4x1.8 GHz Cortex-A510)
GPU     | Immortalis-G710 MC10
Memory  | 8/12GB, LPDDR5X
Storage | 128/256GB, UFS 3.1
Shipped Android Version | 12
Battery | Non-removable Li-Po 5160 mAh battery
Dimensions | 163.6 x 74.6 x 8.16 mm 
Display Type | AMOLED, 68B colors, 120Hz, Dolby Vision
Display Size | 6.73 inches
Display Resolution | 1440 x 3200 pixels
Rear Camera 1 | 50 MP
Rear Camera 2 | 13 MP
Rear Camera 3 | 5 MP
Front Camera | 32 MP
